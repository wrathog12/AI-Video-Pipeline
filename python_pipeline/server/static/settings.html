Providers (R7)

Each of these is an interface with more than one implementation, so swapping one is a config edit rather than a code change. Options that cannot run on this machine are shown disabled with the reason — probed at page load by importing the module or checking for a key, not declared in a list. A dropdown that offers a provider which would crash is worse than no dropdown.

providers.renderer is intentionally not editable here: it selects a code path that shells out to npx remotion and has exactly one implementation, so a dropdown would be attack surface with no feature behind it.

Typography & palette (R7)

Only fonts actually vendored under remotion_engine/public/fonts/ are listed. A font name in a config file is not a font: this dropdown set a string the renderer ignored until src/fonts.ts started registering the faces, so the list is built from files on disk.
